## Projeto em destaque

### Network_Scanner

Ferramenta experimental de análise e diagnóstico de redes desenvolvida utilizando **Rust, Tauri e React**.

O projeto começou como um scanner concorrente de portas TCP, mas a proposta é evoluí-lo gradualmente para uma suíte de estudo e análise de redes.

Entre as funcionalidades atuais e planejadas estão:

* TCP Port Scanning
* UDP Scanning
* descoberta de dispositivos na LAN
* identificação de IP e MAC
* ARP e ICMP
* identificação de serviços
* banner grabbing
* packet sniffing
* análise de protocolos
* DNS
* traceroute
* interfaces de rede
* NAT e CGNAT
* análise de tráfego
* dashboard gráfico

O objetivo principal é compreender os mecanismos existentes por trás de ferramentas profissionais de redes e segurança através da implementação dos seus fundamentos.

[Network_Scanner](https://github.com/Itaxao/Network_Scanner)
